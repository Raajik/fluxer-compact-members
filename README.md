# Fluxer compact sidebars

Custom CSS for Fluxer (https://fluxer.app). It shrinks two sidebars:

- The member list becomes a narrow column of avatars.
- The channel list becomes a narrow column with the server name.

Hover a narrow column to expand it over the chat.

## Use

1. Open User Settings → Look & feel → Theme → "Open theme studio…".
2. Paste the content of `compact-members.css` into Quick CSS.

`SPEC.md` records the behavior, the constraints and the acceptance checks.

Built against fluxerapp/fluxer commit 2ffe8f3 (2026-10-12).
